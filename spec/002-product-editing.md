# SPEC-002: Редактирование продукта

Статус: planned · Волна 1 · Приоритет: средний

## Проблема

`PUT /api/products/{product_id}` (`api/routers/products.py:197`) — полная перезапись тела продукта, UI-редактирования названия/описания нет.

## Решение

1. `PATCH /api/products/{product_id}` с полями `{name?, description?, owner_id?}`:
   - право — manage (rw: админ, владелец, менеджер с грантом rw — матрица SPEC-001);
   - `name`: непустое, trim; `description`: произвольный текст; `owner_id`: пользователь существует, иначе 400;
   - 404 на неизвестный продукт; ответ — обновлённый Product (с `?light=1`).
2. `PUT` остаётся как есть (совместимость).
3. UI: inline-редактирование названия и описания на странице продукта (карандаш → форма → PATCH); смена владельца — контрол в секции настроек, видимая при manage.

## Не-цели

- Редактирование артефактов через эту форму (есть свои эндпоинты), optimistic locking.

## Критерии приёмки

- Unit/интеграционные тесты: PATCH валиден (частичное обновление), 400/403/404-ветки, смена владельца.
- Ручная проверка UI: правка названия/описания, смена владельца, отображение без перезагрузки.
- `bun run lint`, `bun run build` зелёные.
