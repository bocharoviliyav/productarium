# SPEC-022: Textarea промптов занимает весь редакторский div

Статус: planned · Волна 12 · Приоритет: низкий

## Проблема

В `PromptsSection` (src/app/admin/page.tsx ~3020-3073) грид `md:grid-cols-[220px_1fr]`: слева список файлов промптов, справа Card-редактор. Grid-item Card растягивается на всю высоту строки грида (задаётся длинным списком слева), но `Textarea` с фиксированным `rows={20}` занимает лишь часть карточки — под ним пустота, «textarea не занимает весь вышестоящий div» (CSS-путь пользователя: `div.grid.gap-4.md:grid-cols-[220px_1fr] > div > div > textarea`).

## Решение

- Card редактора: `flex flex-col`; внутренний контейнер (`div.space-y-3`) → `flex flex-1 flex-col` с тем же отступом между строками (gap-3).
- `Textarea`: добавить `flex-1` (ширина уже `w-full` из FIELD_BASE) — занимает всю оставшуюся высоту карточки; `rows={20}` сохранить как минимальную высоту.
- Мобильная раскладка (grid-cols-1) не ломается.

## Критерии приёмки

- Textarea заполняет редакторскую карточку по ширине и высоте; пустота под ней отсутствует.
- `bun run lint` / `bun run build` зелёные.

## Затрагиваемые файлы

`src/app/admin/page.tsx` (PromptsSection, ~3042-3073).
