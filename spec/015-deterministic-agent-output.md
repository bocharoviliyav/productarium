# SPEC-015: Детерминированный вывод агентов

Статус: planned · Волна 9 · Приоритет: высокий

## Проблема

Сгенерированные страницы (особенно по коду) нестабильны: модель «залипает» (не завершает секцию, уходит в лишние tool-calls, пролог/эпилог вокруг контента). Причина — отсутствие строгого Output contract в юнит-промптах. Сегодня контракт есть только в части промптов (`refs/prompts/ru/`: только `database_entity.md`; en: docgen_router, docgen_judge, spec_agent_system, spec_enrich_task, hld_page, database_doc, docgen_decomposer, deep_research_synthesizer). Юнит-промпты (docgen_agent_section/subpages/sections, database_tables/categories/relations) — без контрактов; качество держится на верификаторах, которые чинят формат задним числом (retry-петли, деградации).

## Решение

Профилактика вместо починки:

- Строгий Output contract в конце КАЖДОГО юнит-промпта ru+en (docgen_agent_section, docgen_agent_subpages, docgen_agent_sections, database_tables, database_categories, database_relations, database_entity — сверить полный список по факту): маркеры начала/конца секции, запрет пролога/эпилога/пояснений, запрет tool-calls в финальном ответе, язык вывода, формат заголовков.
- Превентивная формат-валидация до верификаторов: расширение гейта SPEC-004 (`run_with_page_gate`) — быстрые структурные проверки (маркеры на месте, нет обрыва текста) с точечным retry (с указанием нарушения) до тяжёлых верификаторов; структурный сбой — не деградация, а retry.
- Per-unit wall-clock бюджеты + watchdog против «залипаний»: юнит-агент без прогресса сверх бюджета → отмена и retry/fallback (единый механизм для codebase-юнитов и `_run_deep_units`).
- Промпты меняются минимально: контракт — единый переиспользуемый блок, не копипаста в каждом файле (переиспользование через `load_prompt_file`/шаблонизацию реестра).

## Критерии приёмки

- Все юнит-промпты ru+en содержат контракт; тест реестра промптов перечисляет файлы с контрактом и падает при появлении нового юнит-промпта без него.
- Гейт: структурный сбой триггерит retry с фидбеком (тест на мок-агенте, возвращающем мусор → вторая попытка чистая).
- Watchdog: мок-юнит без завершения отменяется по бюджету, джоба продолжает остальные юниты.
- Полный прогон: 3259+ passed / 0 failed.

## Затрагиваемые файлы

`refs/prompts/{ru,en}/*.md` (юнит-промпты), `api/prompts.py` (если общий блок), `api/docgen/_common.py` (гейт/watchdog), `api/docgen/codebase.py`, `api/docgen/database.py` (бюджеты юнитов), `api/config/timeout.py` (wall-clock бюджеты), тесты `test_docgen_codebase.py`, `test_docgen_database.py`.
