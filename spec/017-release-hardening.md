# SPEC-017: Предрелизный харднинг

Статус: planned · Волна 10 · Приоритет: высокий (финал перед релизом)

## Проблема

Перед продом нужно чистое состояние: за волнами 1–6 накопился мёртвый/дублированный код обратной совместимости, отдельные wont-fix решения В6 (S-9 typing, P-5 scope) стоит пересмотреть, новые фичи (инкремент, шедулер, граф знаний, SPEC-011..016) не проходили целевого ИБ-фокуса. README/.env.example/docker-compose могут отставать от реальности.

## Решение

Финальный проход по чек-листу:

- **Мёртвый/back-compat код**: найти и удалить пути совместимости, более не актуальные после закрепления новых форматов (introspection cache v6, source_state SPEC-010, версии SPEC-012) — каждый кандидат на удаление проверяется грепом на референсы, дубликаты схлопываются по DRY.
- **Ревизия wont-fix В6**: S-9 (typing) и P-5 (scope-колонка) — реализовать или зафиксировать осознанный отказ с обоснованием.
- **ИБ-фокус новых фич**: ревью инкрементальных detect/increment эндпоинтов, шедулера, графа знаний, REA-пресета, новых REST (version delete, дельта-версии) — auth/RBAC-гварды, инъекции, таймауты, утечки секретов; инварианты AGENTS.md (fs confinement, маскирование, полиси) — на месте.
- **Актуальность окружения**: README, .env.example (только документируем переменные, файл не читаем), docker-compose — сверены с текущими настройками/таймаутами/гейтами.
- **Техдолг**: TODO/FIXME-маркеры в коде — выполнить или превратить в issue-записи; flaky-тест `test_legacy_docs_get_baseline_then_generate` — стабилизировать или изолировать.
- **Финальный полный прогон**: полный pytest-сьют, `bun run lint && bun run build`, — всё зелёное; сводка в spec/README.md.

## Критерии приёмки

- Греп-отчёт: удалённые back-compat пути не имеют живых референсов; сьют зелёный после удалений.
- wont-fix пункты закрыты решением; ИБ-ревью новых фич без open-критикалов.
- README/.env.example/docker-compose актуальны; финальный прогон зелёный.
