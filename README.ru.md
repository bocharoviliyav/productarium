# Productarium

> Продукто-центричная платформа технической документации с полностью локальными LLM: облачные API-ключи не требуются.

Productarium превращает репозитории, спецификации OpenAPI/AsyncAPI, ссылки, базы данных и страницы знаний в связную, индексированную, верифицируемую документацию. Каждый **Продукт** владеет типизированными сущностями — **кодовая база**, **спецификация**, **ссылки**, **база данных** — и деревом **узлов знаний**. Агентный стек построен на **LangChain / LangGraph**: пайплайн **deepagents** генерирует документацию по кодовой базе с проверкой цитат и LLM-судьёй, **Deep Research** отвечает на исследовательские вопросы за несколько итераций, базы данных реверс-инжинирятся через **MCP-интроспекцию**. Семантическая память работает напрямую на **PostgreSQL + pgvector** (косинусный поиск, индекс HNSW).

## Быстрый старт

```bash
# Docker Compose: postgres (pgvector) + productarium (FastAPI :8001, Next.js :3000)
cp .env.example .env
docker-compose up

# Бэкенд (разработка)
python -m pip install poetry==2.0.1 && poetry install -C api
python -m api.main

# Фронтенд
bun install
bun run dev
```

На хосте должен работать OpenAI-совместимый сервер (LM Studio / llama.cpp / vLLM) с моделью генерации и моделью эмбеддингов; при первом запуске UI предложит создать администратора. Требования, архитектура, переменные окружения, тестирование и troubleshooting — в [README.md](./README.md).
