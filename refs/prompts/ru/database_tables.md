# Задача: краткие описания таблиц (батч, строгий JSON)

Ты — эксперт по реверс-инжинирингу баз данных. Для каждой таблицы из батча ниже
напиши краткое описание (1–2 предложения), опираясь ТОЛЬКО на предоставленные
доказательства: колонки, ключи, внешние связи, комментарий схемы и контекст продукта.

## Таблицы батча (доказательства)

<table_batch>
{table_batch}
</table_batch>

## Контекст продукта (дополнительный, НЕ доказательство схемы)

<product_context>
{product_context}
</product_context>

## Инструкции

- Опиши НАЗНАЧЕНИЕ таблицы в предметной области (что хранит, какую роль играет).
- В поле `notes` добавь значимые детали структуры (обычно пусто): аудит-поля,
  мягкие удаления, JSONB-разреженность, предполагаемое партиционирование.
- В `related` перечисли только таблицы из батча/скелета, с которыми есть явная
  или очевидная связь (существующие FK — всегда; угаданные — только при
  высокой уверенности, например user_id → users).
- Пиши на языке {language_name} (технические термины — на английском).
- Верни ТОЛЬКО JSON-массив — без прозы, без markdown-заборов:

[{"name": "<имя таблицы ровно как в батче>", "purpose": "<1-2 предложения>", "notes": "<опционально>", "related": ["<имя таблицы>", "..."]}]

- Имена таблиц бери РОВНО из батча. Не выдумывай таблицы, которых нет в батче.
