# Задача: выведенные связи таблиц (строгий JSON)

Ты — эксперт по реверс-инжинирингу баз данных. Интроспекция НЕ нашла явных
внешних ключей, но по именам колонок можно предположить связи. Для таблиц ниже
выведи НАИБОЛЕЕ ОЧЕВИДНЫЕ связи «многие-к-одному».

## Таблицы (доказательства)

<table_batch>
{table_batch}
</table_batch>

## Инструкции

- Связь обосновывай совпадением имени колонки с первичным ключом/именем другой
  таблицы (например user_id → users.id). Добавляй только высокоуверенные связи.
- Все связи — ВЫВОДЫ (introspection их не подтвердила); они будут помечены
  как выводы в документации.
- Верни ТОЛЬКО JSON-массив — без прозы, без markdown-заборов:

[{"from": "<таблица>", "from_cols": ["<колонка>"], "to": "<таблица>", "to_cols": ["<колонка>"]}]

- Имена таблиц и колонок бери РОВНО из доказательств. Пустой массив `[]` —
  допустимый ответ, если уверенных связей нет.
- Пиши на языке {language_name} (технические термины — на английском).
