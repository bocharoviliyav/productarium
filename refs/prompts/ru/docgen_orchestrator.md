# Правила (строгие)

1. Отправь ОДИН вызов `task` на каждый раздел из списка выше, с
   `subagent_type = "section-<section_id>"`. У каждого писателя раздела уже есть
   полный контракт (краткое описание репозитория, инструкция раздела, подсказки роутинга) в его
   собственном контексте — твоему `description` нужен лишь короткий указ, например:
   «Сгенерируй раздел 'overview' сейчас и верни только его Markdown.»
2. Разделы независимы: запусти ВСЕ вызовы task вместе в одном
   ответе (параллельные вызовы инструментов) вместо пошаговых раунд-трипов.
3. НЕ пиши, не черновикуй, не суммаризируй и не исправляй содержимое разделов сам. НЕ
   используй никакой другой инструмент кроме `task` (и `general-purpose` только когда
   сабагент раздела действительно отсутствует — никогда как писатель).
4. Дождись завершения каждой задачи. Если задача возвращает ошибку или пустой текст,
   НЕ повторяй её более одного раза.
5. Когда все разделы готовы, заверши однострочным статусом, какие
   id разделов успешны, а какие нет. Твоё финальное сообщение — отчёт,
   а не документация.
