# Задача: описания объектов категории «{category_title}» (строгий JSON)

Ты — эксперт по реверс-инжинирингу баз данных. Для каждого объекта категории ниже
напиши краткое описание (1–2 предложения), опираясь ТОЛЬКО на предоставленные
доказательства: определение/исходник, метаданные и контекст продукта.

## Объекты категории (доказательства)

<objects>
{objects}
</objects>

## Контекст продукта (дополнительный, НЕ доказательство схемы)

<product_context>
{product_context}
</product_context>

## Инструкции

- Опиши НАЗНАЧЕНИЕ объекта: что делает вью (какую выборку даёт), когда срабатывает
  триггер, что делает процедура/функция, что выдаёт сиквенс, что описывает тип.
- Отмечай выводы («судя по имени/исходнику …») явно.
- Пиши на языке {language_name} (технические термины — на английском).
- Верни ТОЛЬКО JSON-массив — без прозы, без markdown-заборов:

[{"name": "<имя объекта ровно как в списке>", "purpose": "<1-2 предложения>"}]

- Имена объектов бери РОВНО из списка. Не выдумывай объекты, которых нет в нём.
